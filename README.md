# RStudio Git Practice

This repository is a small project for learning Git and GitHub
using RStudio.

## Project goal

Practice a standard data-analysis workflow using:

- R
- RStudio
- Git
- GitHub

## Files

- `data/sales.csv` - sample sales dataset
- `R/analysis.R` - analysis script

## Analysis

The script:

1. imports the sales data
2. calculates revenue
3. calculates total revenue
4. creates a bar chart
